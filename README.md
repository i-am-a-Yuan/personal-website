#### 已知的问题和解决方案

- > 【已更新】`ArticleManager.jsx` 中使用了 `async-await` 结构，在 `ESLint v9.0.0` 环境下使用 `npm run build` 构建会引发 `[vite:esbuild] Transform failed`，报错信息为 `"await" can only be used inside an "async" function`。
    > 原因是ESLint 旧解析器默认 `ecmaVersion` 过低，文件被错误识别。
    > 一种可行的解决方案是跳过语法静态检查，直接使用 `npx vite build` 进行构建，无需升级版本或引入其他依赖。
    > 已修改对应代码，确认是代码编写出现结构错误和部分缺失，现无此问题。

#### 如何更好地开发和部署

##### 开发流程

我个人的开发流程是：从 `dev` 分支出 `feature1` 和 `worktree`，`worktree` 交给 AI agent，AI agent 完成开发后在 `feature1` 上对其合并，分别进行前端和后端测试，测试通过后使用 `docker` 运行，运行通过后提交 `feature1` 分支，并在 `dev` 分支对 `feature1` 分支进行合并，重新测试对比，并更新文档，`push` 到 github。
